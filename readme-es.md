este repositorio está en español debido 
a que es mi lenguaje materno, 
a futuro pienso hacerlo en ingles y español, así que una 
espera para la versión en inglés no sería malo

la guía es NO OFICIAL, así que esto UNOFICIAL (no oficial)

los .odt que verás sirven para esto:

make.conf: configuración basica

USEFLAGS.odt: sirve para enseñarte lo super basico de las USE

Portage.odt / emerge.odt: Guía NO OFICIAL de portage que te guia de una forma tan KISS que parece broma

package.use.odt: USEFLAGS especificas de cada paquete, solo 2 ejemplos

package.accept_keywords.odt: ~amd64

kernel-gentoo.odt: explica los 3 kernels que hay

gentoolkit.odt: limpieza del sistema

eselect-repository.odt: funciona para escojer repositorios de X repo o Y repo

Block.odt: paquetes bloqueados

examples.odt: sintaxis de emerge

el proyecto está en alfa, se piensa hacer una distro a base de esto, para nuevos usuarios
todo por amor al arte
