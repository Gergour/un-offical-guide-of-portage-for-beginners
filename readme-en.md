This repository is in Spanish because it is my native language. In the future, I plan to make it available in both English and Spanish, so waiting a bit for the English version shouldn't be an issue[cite: 1].

The guide is UNOFFICIAL, so consider it unofficial[cite: 1].

Here is what the `.odt` files are for[cite: 1]:

* **make.conf:** Basic configuration[cite: 1].
* **USEFLAGS.odt:** Teaches you the super basics of USE flags[cite: 1].
* **Portage.odt / emerge.odt:** UNOFFICIAL Portage guide written in such a KISS (Keep It Simple, Stupid) way that it almost feels like a joke[cite: 1].
* **package.use.odt:** Package-specific USE flags, includes just 2 examples[cite: 1].
* **package.accept_keywords.odt:** ~amd64 configuration[cite: 1].
* **kernel-gentoo.odt:** Explains the 3 available kernels[cite: 1].
* **gentoolkit.odt:** System cleanup[cite: 1].
* **eselect-repository.odt:** Used for selecting repositories from repo X or repo Y[cite: 1].
* **Block.odt:** Blocked packages[cite: 1].
* **examples.odt:** Emerge syntax examples[cite: 1].

The project is currently in alpha, with plans to build a 
custom distribution based on this for new users[cite: 1]. 

Everything is done purely for the love of art[cite: 1].
