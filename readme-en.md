This repository is in Spanish because it is my native language. In the future, I plan to make it available in both English and Spanish, so waiting a bit for the English version shouldn't be an issue.

The guide is UNOFFICIAL, so consider it unofficial.

Here is what the `.odt` files are for:

* **make.conf:** Basic configuration.
* **USEFLAGS.odt:** Teaches you the super basics of USE flags.
* **Portage.odt / emerge.odt:** UNOFFICIAL Portage guide written in such a KISS (Keep It Simple, Stupid) way that it almost feels like a joke.
* **package.use.odt:** Package-specific USE flags, includes just 2 examples.
* **package.accept_keywords.odt:** ~amd64 configuration.
* **kernel-gentoo.odt:** Explains the 3 available kernels.
* **gentoolkit.odt:** System cleanup.
* **eselect-repository.odt:** Used for selecting repositories from repo X or repo Y.
* **Block.odt:** Blocked packages.
* **examples.odt:** Emerge syntax examples:

The project is currently in alpha, with plans to build a 
custom distribution based on this for new users
